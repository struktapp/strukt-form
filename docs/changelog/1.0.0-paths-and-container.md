# 1.0.0 — Align contract/base paths and resolve forms from container

## What changed

- `composer.json`: path repositories now point to `../../strukt4/contract`
  and `../../strukt4/base` (from `../../strukt3/...`), matching the `strukt4`
  directory layout.
- `src/helpers.php`: the `form()` helper now instantiates forms through
  `app($class)` when the container is available, otherwise falls back to
  `new $class()`.

## Why

- `strukt4` relocated its packages; the form package's local path dependencies
  still pointed to `strukt3` and would fail to resolve the correct sources.
- Forms should be constructible through the shared container so services can
  be injected into form instances.

## Documentation

- None.

## Tests

- Existing form tests continue to pass (21 tests, 51 assertions).

## Public API impact

- Packaging/bootstrapping only; no contract changes to `Strukt\Form\Form` or
  its helpers.
